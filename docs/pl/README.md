# Dokumentacja (polski)

FortiGate VPN Linux GUI to niezależny, otwarty klient pulpitu dla FortiGate
SSL VPN na systemie Linux.

**Ten projekt nie jest powiązany, wspierany ani sponsorowany przez Fortinet.**
Fortinet, FortiGate i FortiClient są znakami towarowymi odpowiednich
właścicieli.

Wersja v0.2.x dodaje trwałe profile połączeń. Łączność VPN oraz SAML/SSO są
planowane i nie są zaimplementowane.
