# Assets

Application icons live in the Python package:

```text
src/fortigate_vpn_gui/resources/icons/fortigate-vpn-linux-gui.svg
```

That file is original project artwork (a generic network node). It is not a
Fortinet or FortiGate logo. The Debian package also installs it to

```text
/usr/share/icons/hicolor/scalable/apps/fortigate-vpn-linux-gui.svg
```

Tray connection-state icons remain generated at runtime.
